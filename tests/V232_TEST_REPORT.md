1. 取消四级背景衰减，连续精读区域在所有块中保持同一主题填充色。
2. 每个视觉区域起点增加 10px 间隙，边框使用小圆角自然收口，无外框或阴影。
3. 标题、列表、引文、原文译文对照、表格和分隔线按 Agent 角色信息强制断区。

5. 新增预览范围、正文段落数量、三主题填充和跳读预览不触发聚焦的真实浏览器断言。

## 真实浏览器覆盖

- computed style：精读暖底、3px 区域边框、局部 700 字重；速览正常正文色、400 字重、无填充。
- 文字与结构：辅助正文与原文逐字一致，段落数量一致，无字数减少或列表化。
- 区域：区域数少于语义块数；长区域所有精读块背景一致；连续块边框为 0，区域边框保留。
- 结构：列表 fixture 强制断区；同主题跳读合并，跨主题不合并。
- 起点：区域 `margin-top:10px`，无卡片阴影。
- 跳读：预览关闭时可见，只描述区域范围；点击预览只展开/收起，不进入聚焦。
- 聚焦：当前句高亮、其他块减淡、静态块填充让位；点击空白不改变焦点；关闭后恢复。
- 对比度：浅色减淡、深色高亮、深色减淡、护眼正文均 ≥4.5:1；深色高亮与页面背景有可测亮度差。
- 三主题：白色、深色、护眼精读填充均与页面背景可辨，且保留 3px 边框，不存在只剩边框的情况。
- 原文：逐字一致、分段保留、包含折叠内容；无 `<strong>`、区域、折叠、边框、填充、阴影或加粗残留。
- 导航与模式：真实 ArrowRight 不进入折叠内容；原文和模式切换保留阅读位置；完整阅读直接展示全部内容。
- 移动端：390×844 视口无横向溢出，工具栏触摸目标 ≥44px。

## 限制

- 真实浏览器验证覆盖 Chromium；未覆盖 Firefox、Safari 和真实触屏设备。
- 结构边界依赖 Agent 正确提供角色；若模型未识别标题、列表或表格，HTML 不会从正文关键词重新推断。
- 预览是否属于“只描述范围”仍首先由 Agent 保证；自动化仅对示例文本做范围、长度和非摘要检查，不能普遍证明语义质量。
