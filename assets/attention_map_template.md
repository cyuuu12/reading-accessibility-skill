# 注意力地图模板（V2.1 · 用户层）

> 每段一行。加粗优先级标签 + 语义色 + 具体理由。**不使用符号，不展示 ACS 原始分数，不展示跳读损失%**。

```
# 阅读路线

阅读难度：适中

段 1  **重点读**｜翻译理论 — 是后文分析的理论基础。
段 2  **简单读**｜借词实例 — 可快速读。
段 3  **可略读**｜重复举例 — 略过不影响结论；可展开。

重点读段占比：NN%（论文类建议 ≤25%，仅信息不作硬门槛）
是否建议分篇/分段：是/否
```

## 填写规则
- 标签三选一：**重点读**（蓝）/ **简单读**（绿）/ **可略读**（灰），加粗 + 语义色。
- 每段附**具体理由**（不套模板），说明为什么是这个优先级。
- 可略读段附"略过会漏什么"的具体说明。
- 优先级由 `references/routing.md` 语义功能优先判定（结合用户目标）。
- 阅读难度描述：较低 / 适中 / 较高 / 很高（由 ACS 区间映射，不展示原始分数）。
