# 注意力地图模板（V2.0 · 用户层）

> 每段一行。加粗优先级标签 + 一句通俗原因。**不使用符号，不展示 ACS 原始分数，不展示跳读损失%**。

```
# 阅读路线

阅读难度：适中

段 1  **重点读** — <结论与关键条件>，建议优先阅读。
段 2  **简单读** — <背景补充>，快速过即可。
段 3  **可略读** — <重复举例>，略过不影响结论；可展开。
...

重点读段占比：NN%（论文类建议 ≤25%）
是否建议分篇/分段：是/否
```

## 填写规则
- 标签三选一：**重点读** / **简单读** / **可略读**，加粗显示。
- 每段必附一句通俗原因（≤20 字），说明为什么是这个优先级。
- 可略读段附"略过会少了解…，不影响…"的具体说明。
- 优先级由 `references/routing.md` 规则判定（结合结论负载 + 用户目标）。
- 阅读难度描述：较低 / 适中 / 较高 / 很高（由 ACS 区间映射，不展示原始分数）。
