# 辅助阅读 Markdown 模板（V2.2 简化版）

> Markdown 是正式轻量输出，也可作为 HTML 不可交付时的降级方案；与 HTML 共用一次结构化分析结果，不模拟阅读器控件。
> 三级策略、折叠、字号控制等交由 HTML 或宿主原生组件处理。

## 模板

```
# {标题}

{如有必要，简洁的模块化理解框架，仅复杂文本才生成，不机械套用}

{原文段落 1，保持原文顺序}

{原文段落 2}

{原文段落 3}

…

{末尾可选：少量辅助提示，如"段 X 句子较长建议分段读"，不逐段总结}
```

## 约束
- 保留原文顺序与主体内容，不逐段总结或改写全文。
- 不为每段生成标题，不反复出现"重点读/简单读"标签。
- 仅在需要处用少量加粗、段落分隔和简短解释。
- 不使用大量标题、引用块和加粗造成视觉竞争。
- 模块化理解框架仅在复杂文本确有必要时简洁展示。
- 三级策略不在 Markdown 中表达。
- 数字/单位/否定/限定/因果/条件/比较/范围须与原文一致。
- 中英混排保持原有顺序与对应关系。
