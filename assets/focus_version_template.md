# 单行聚焦版模板（V2.0）

> 一行一句，行长按语义边界动态调整（不机械限 40 字）。指代已消解。
> 用**加粗/缩进/空行**区分结论行与支撑行，**不使用特殊符号**。

```
# 辅助阅读版

**结论：<结论句，长度由核心信息量决定>**

  <支撑句 1，代词已替换为实词>
  <支撑句 2>

**结论：<下一段结论>**

  <支撑句…>
```

## 排版约束（软性）
- 每行一句（以。！？；结尾），按语义边界断行，不机械切断。
- 结论行**加粗**并顶格；支撑行缩进两空格。
- 段间空行分隔。
- 不得出现未消解代词；无法确定时标注"（指代：？）"。
- 数字/单位/否定/限定/因果/条件/比较/范围须与原文一致。
- 复杂术语首次出现可附简短解释（不替换必要专业概念）。
