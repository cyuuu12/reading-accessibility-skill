# 阅读路由 · 重点读 / 简单读 / 可略读（V2.0）

> V2.0 重大修订：取消 V1 的"精读/速览/可跳 + 跳读损失百分比"抽象分类。
> 改为面向用户的**阅读优先级提示 + 可选择的内容折叠**，用**加粗标签 + 一句通俗原因**表达，**不使用任何符号**。

---

## 1. 三个优先级标签

| 标签 | 含义 | 用户动作 |
|------|------|----------|
| **重点读** | 含核心结论/重要定义/关键论据/必要条件 | 建议优先阅读 |
| **简单读** | 含辅助解释/背景信息/补充论据 | 可快速阅读 |
| **可略读** | 与当前阅读目标关联较弱，或对已理解内容重复举例 | 可选择暂时略过 |

**呈现方式**：加粗标签 + 一句通俗原因。例如：

> **重点读** — 本段给出主结论与适用条件，建议优先阅读。
> **简单读** — 本段是背景补充，快速过即可。
> **可略读** — 本段是重复举例，略过不影响主要结论；需要时可展开。

**禁止**：只用符号表示优先级；只给标签不给原因；给出抽象的跳读损失百分比数值。

---

## 2. 判定规则（按优先级）

### 2.1 文档级硬规则
- **药品说明书 / 合同 / 法律材料**：默认**完整阅读**，全段不得标"可略读"；不自动省略警示/限定/关键条件/例外。若用户要摘要，必须标明"摘要不能替代原文"。
- 合同中含否定/限定/条件的段：强制 **重点读**。

### 2.2 结论负载判定（先于 ACS）
段含以下任一 → 有结论负载：
- 数字 / 单位 / 否定词 / 限定词 / 条件词 / 因果词 / 比较词 / 数量范围
- 定义、结论、警告、要求、例外、反例、关键证据

段为以下 → 无结论负载：
- 纯举例、过渡、重复、背景铺陈（且与用户当前目标关联弱）

### 2.3 优先级判定
- **有结论负载** → **重点读**（无论 ACS 高低）。
- **无结论负载**：
  - 与用户目标关联中等 → **简单读**。
  - 与用户目标关联弱 / 重复举例 / 纯过渡 → **可略读**。
- ACS 仅作辅助参考：ACS 很高的"简单读"段可提示"本段较长，可按需展开"，但**不**因此升为重点读或降为可略读。

### 2.4 用户目标加权
- 判定"关联强弱"须结合用户阅读目标（如用户只要结论，则背景铺陈→可略读；用户要理解推导，则论据→重点读）。
- 无明确目标时按内容结构默认判定，并在路线末尾提示"如你的阅读目标不同，可告知我重新标注"。

---

## 3. 折叠与确认机制

- **默认保留全部原文**，不自动删除/永久隐藏。
- **完整阅读**：不折叠。
- **聚焦阅读**：低优先级（可略读）内容可折叠，**始终支持展开**。
- **快速浏览**：仅显示路线 + 重点读内容，原文始终可访问。
- 需真正跳过内容时，**一次性**明确询问，例如：
  > "是否暂时折叠补充举例和重复说明？随时可以展开查看原文。"
- 用户已选模式后，**不每段重复询问**。
- **可略读 ≠ 无价值 ≠ 可安全删除**。

---

## 4. 略读说明（替代抽象的跳读损失百分比）

不输出抽象百分比数值，改为**具体说明可能遗漏的信息**：
- "略过这里会少了解一个吸收过程的例子，不影响主要结论。"
- "略过这里会跳过背景介绍，不影响用药结论。"
- 对重点读段：不提供略读选项（"本段含关键条件，不建议略过"）。

---

## 5. 必要内容保护

以下内容**不得**因文本较长被标为可略读：
- 必要定义、条件、例外、反例、关键证据
- 数字、单位、否定、限定、因果、比较、范围
- 警示、禁忌、不良反应、剂量上限/下限

---

## 6. 路由输出格式（用户层）

每段一行，加粗标签 + 原因：
```
段 3  **重点读** — 主结论与适用条件，建议优先阅读。
段 7  **简单读** — 吸收过程背景补充，快速过即可。
段 9  **可略读** — 重复举例，略过不影响结论；可展开。
```
末尾报告：重点读段占比、是否建议分篇/分段、（论文类）重点读占比是否 ≤25%（超出则回切分压缩重点段数）。

---

## 7. 典型例子与边界

- **定义段** → 重点读（结论负载：定义）。
- **纯举例段且用户已懂结论** → 可略读，附"略过不影响结论"。
- **举例段但用户目标是理解推导** → 简单读（关联中等）。
- **含"不超过 40mg"的剂量段** → 重点读（数字+限定），高风险禁略。
- **过渡句"综上所述，以上分析表明…"** → 简单读或可略读，看是否承载新结论。
- **反例段** → 重点读（反例受保护）。
