# 阅读路由 · 语义分析与阅读呈现（V2.3）

> V2.3：语义分析由 Agent（宿主模型）完成，Python 只做切分/校验/呈现；
> 60% 降为诊断不阻断；语义块替代逐句切分；HTML 去标签视觉分层。

---

## 三层分工

| 层 | 职责 | 禁止 |
|----|------|------|
| **Agent**（宿主模型） | 根据全文上下文、论证关系和阅读目标判断语义功能及优先级 | 不得用关键词规则或脚本代替 |
| **Python**（analyze.py） | 原文切分、数据结构、边界校验、保真校验、诊断统计 | 不判断语义重要性 |
| **HTML** | 呈现与交互 | 不重新判断语义重要性 |

---

## Agent 语义分析 schema

Agent 读取全文后，按以下 JSON 格式输出结构化分析结果：

```json
{
  "goal": "聚焦阅读",
  "blocks": [
    {
      "para_idx": 0,
      "text": "根据纽马克的翻译理论……两种侧重形式。",
      "role": "理论定义",
      "priority": "精读",
      "preview": null
    },
    {
      "para_idx": 2,
      "text": "例如，在《红楼梦》英译本中……",
      "role": "例证",
      "priority": "跳读",
      "preview": "《红楼梦》英译中缘分的借词实例"
    }
  ]
}
```

### 字段说明
- `para_idx`：自然段索引（0-based）。
- `text`：该语义块的原文，必须在对应自然段中精确定位。
- `role`：语义功能（理论定义/核心论点/论证/例证/背景/过渡/限定/结论/引文）。
- `priority`：精读 / 速览 / 跳读。
- `preview`：仅跳读块需要，描述"这块是什么"（不复述内容）。

### Python 三硬约束
1. 每个 block 的 `text` 能在原文中精确定位。
2. block 之间互不重叠。
3. 全部 block 覆盖原文无遗漏（非空白字符一致）。

任一失败 → 该段退回保守处理（整段单块、无标签、不折叠），记录问题段落。

### 保守模式
无 LLM 语义分析时（`analysis=None`）：全文按原文呈现，不贴标签，不折叠。不得把关键词分类冒充语义理解。

---

## 语义块（非逐句切分）

- 一个语义块可含多句，长度由意义完整性决定。
- 相邻句子属于同一论证功能时合并。
- 默认不跨自然段；段落仍是视觉容器。
- 逐句高亮保留，只在块内部定位句子，不决定切分单位。
- 记录语义块数与块内句子数，供测试判定合并是否生效。

## 三种阅读行为

### 精读
- 完整保留原文。
- 核心论点、必要推理、关键定义适度加粗。
- 需要时提供局部解释，不默认改写。

### 速览
- 默认直接显示主要内容，不需点击展开。
- 保留核心意思和必要上下文。
- 适度压缩重复说明，原文必须可恢复。
- **不等于折叠或逐段摘要。**

### 跳读
- 仅用于对当前阅读目标非必要的重复例证、次要背景或补充内容。
- 显示一句结构性预览（"这块是什么"），不复述内容。
- 用户可展开完整原文。
- 相邻同主题跳读块合并为一个折叠区；跨主题不合并。

不强制三类占比，不为增加跳读比例而隐藏关键证据。

---

## 60% 诊断（不阻断）

- 统计精读占比、段内切分率、单标签整段占比、问题段落列表。
- 超过 60% 时输出诊断信息，**不阻断输出**，不强行降级。
- 诊断写入 `_meta.diagnostic`。

---

## HTML 呈现（无标签视觉分层）

取消正文中"重点读/简单读/可略读"标签、段落编号及判断理由。

| 行为 | 视觉 |
|------|------|
| 精读 | 正常深色正文，关键命题适度加粗；橙红色细边可选辅助 |
| 速览 | 正常字号、常规字重，次要内容适度弱化；默认直接可读 |
| 跳读 | 简洁预览 + 灰色"展开原文"入口 |

- 所有正文相同基础字号，允许统一调整。
- 不大面积彩色字体，不仅靠颜色区分。
- 减少卡片、边框、按钮数量。

---

## 聚焦高亮与减淡

- 高亮默认关闭。
- 开启后点句进入聚焦：当前句柔和背景高亮，当前语义块正常，其他语义块减淡。
- **减淡用文字颜色变量（--fg-dim），不用整体 opacity。**
- 减淡后对比度 ≥ 4.5:1，达不到就减少减淡程度。
- 关闭高亮恢复全部正常。
- 折叠/展开/模式切换/原文切换后聚焦状态正确更新。
- 导航不进入不可见内容。

---

## 优先级视觉

| 行为 | 浅色/深色 | 护眼 |
|------|----------|------|
| 精读 | 橙红细边 | 蓝细边 |
| 速览 | 无特殊标记 | 无 |
| 跳读 | 灰色预览 | 灰 |

阅读优先级颜色与按钮/进度条交互颜色分离。

---

## 高风险文本
- 药品说明书/合同/法律：默认完整阅读，不折叠，不标跳读。
- 不自动省略警示/限定/关键条件/例外。
