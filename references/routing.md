# 阅读路由 · 语义分析与复核（V4.0）

> 本文件是 Agent 语义分析、schema 和异常复核的唯一权威来源。
> Markdown / HTML 共用一次 `route_text()` 结果；HTML 视觉与交互规范仅在需要时读取 `reader.md`。

---

## 三层分工

| 层 | 职责 | 禁止 |
|----|------|------|
| **Agent**（宿主模型） | 根据全文上下文、论证关系和阅读目标判断语义功能及优先级 | 不得用关键词规则或脚本代替 |
| **Python**（analyze.py） | 原文切分、数据结构、边界校验、保真校验、诊断统计 | 不判断语义重要性 |
| **HTML** | 呈现与交互 | 不重新判断语义重要性 |

---

## Agent 语义分析 schema

Agent 读取全文后，按以下 JSON 格式输出结构化分析结果：

```json
{
  "goal": "聚焦阅读",
  "blocks": [
    {
      "para_idx": 0,
      "text": "根据纽马克的翻译理论……两种侧重形式。",
      "role": "理论定义",
      "priority": "精读",
      "preview": null,
      "emphasis": [
        {"start": 21, "end": 30, "text": "语义翻译和交际翻译", "score": 0.98}
      ]
    },
    {
      "para_idx": 2,
      "text": "例如，在《红楼梦》英译本中……",
      "role": "例证",
      "priority": "跳读",
      "preview": "《红楼梦》英译中缘分的借词实例"
    }
  ]
}
```

### 字段说明
- `para_idx`：自然段索引（0-based）。
- `text`：该语义块的原文，必须在对应自然段中精确定位。
- `role`：语义功能（理论定义/核心论点/论证/例证/背景/过渡/限定/结论/引文）；标题、章节标题、分隔符、分隔线、列表、原文译文对照、表格是结构角色。
- `priority`：精读 / 速览 / 跳读。标题和分隔符的 priority 必须置空；即使 Agent 误填，Python 也会归一为 null。
- `heading_level`：仅结构标题使用。0 表示文档主标题，1 表示一级章节，2 表示二级章节，3 及以上按实际层级递增；不得凭空制造层级。
- `preview`：仅跳读块需要，描述"这块是什么"（不复述内容）。
- `emphasis`：可选局部强调数组。`start/end` 为相对本块 `text` 的 `[start,end)` 字符区间；`text` 须与区间原文逐字一致；`score` 用于超限截断。只标核心命题、关键概念与必要逻辑，不按关键词机械加粗。

### emphasis 校验
- 非法区间、越界、原文不匹配、跨块及重叠强调不渲染，并记入 `_meta.diagnostic.emphasis.dropped`。
- 每块最多 3 处，每处最多 15 字；全文加粗非空白字符不超过正文的 5%，按 `score` 截断。
- 无有效强调时保持普通正文；强调失败不影响语义块、阅读策略或原文。
- HTML 仅用文本节点和 `<strong>` 插入强调，不把原文当 HTML 拼接，不改字词、标点或译例。

### Python 三硬约束
1. 每个 block 的 `text` 能在原文中精确定位。
2. block 之间互不重叠。
3. 全部 block 覆盖原文无遗漏（非空白字符一致）。

任一失败 → 该段退回保守处理（整段单块、无标签、不折叠），记录问题段落。

### 保守模式
无 LLM 语义分析时（`analysis=None`）：全文按原文呈现，不贴标签，不折叠。不得把关键词分类冒充语义理解。

## 语义块（非逐句切分）

- 一个语义块可含多句，长度由意义完整性决定。
- 相邻句子属于同一论证功能时合并。
- 默认不跨自然段；段落仍是视觉容器。
- 逐句高亮保留，只在块内部定位句子，不决定切分单位。
- 记录语义块数与块内句子数，供测试判定合并是否生效。

---

## 三种阅读行为

### 精读
- 完整保留原文。
- 核心论点、必要推理、关键定义适度加粗。
- 需要时提供局部解释，不默认改写。

### 速览
- 默认直接显示主要内容，不需点击展开。
- 是清晰基准态：正常字号、正常字重、正文色，不删减、不改写文字。
- 仅以行长、段距、可选断行做零信息损失排版辅助，不跨语义块。
- 只有聚焦选中其他内容后才暂时减淡；不等于折叠或逐段摘要。

### 跳读
- 仅用于对当前阅读目标非必要的重复例证、次要背景或补充内容。
- 显示一句结构性预览（"这块是什么"），不复述内容。
- 用户可展开完整原文。
- 相邻同主题跳读块合并为一个折叠区；跨主题不合并。

不强制三类占比，不为增加跳读比例而隐藏关键证据。

## 块级统计与复核

统计直接遍历语义块，使用块级 `priority` 和非空白字符：

- `focus_char_ratio`：精读字符 / 全部带 priority 的正文非空白字符。
- `focus_block_ratio`：精读块数 / 全部带 priority 的正文块数。
- `skip_char_ratio` 与 `skip_block_count`：跳读字符占比与跳读块数。
- 分母含精读、速览、跳读；按 `role`/`structure`/`heading_level` 排除标题、分隔符及其他结构性块。
- `block_lengths` 输出每块字符数、句数、角色和是否结构性块，用于识别长论证段被整段误降级。
- `focus_ratio` 仅保留旧版段级聚合结果作兼容对照，不再用于阈值判断。

### 60% 复核阈值

- 默认阈值 `0.60`，可用 `analysis.focus_threshold` 或 `route_text(focus_threshold=...)` 配置。
- 不同文本类型可调整阈值，但必须有明确依据；不得为通过测试自动提高阈值。
- 超阈值时 `output_status=blocked_pending_agent_review`，Agent 必须重新审查背景、重复解释、次要例证和非必要过渡是否被过度标精读。
- 复核结果通过 `analysis.review` 传入：`performed=true`、`attempt=1..2`、`summary` 必填；最多两次重新分析。
- 复核后仍超阈值时，必须提供 `exception_reason`；此时状态为 `exception_retained`，允许有依据地保留。
- 未复核或复核后无例外原因为 `exception_missing`，不得伪装合格。阈值是强制复核条件，不是机械压缩配额。

### 零跳读适用性复核

- 较长正文（默认非空白字符 ≥1000）`skip_block_count == 0` 时触发一次复核。
- Agent 检查例证是否与解释被过度合并、重复例子能否独立、背景是否非必要、看似举例是否承担关键论证。
- 复核结果通过 `analysis.skip_review` 传入；仍为零跳读时必须记录 `exception_reason`。
- 不得为通过测试强制生成跳读块；关键现象学分析实例、限定、反例和必要证据不得降为跳读。

## 标题层级

- 标题是结构，不是阅读策略；`priority` 置空，不参与精读/速览/跳读比例，也不自动折叠。
- Agent 依据文本结构识别标题，不得仅凭“一、”“1.”或书名号判定。
- 文档主标题渲染 `<h1>`，一级章节 `<h2>`，二级章节 `<h3>`，更深层级按实际递增。
- 标题不添加精读暖底或速览边框，并作为连续视觉区域的边界。
- 保守模式只识别独立成行且编号/章节结构明确的标题；不确定时保留原文，不强行改结构。
- 标题渲染不改原文字符；全局原文模式保留原始标题文字、顺序与换行。

## 高风险文本
- 药品说明书/合同/法律：默认全文可见，不折叠，不标跳读。
- 不自动省略警示/限定/关键条件/例外。
