## 三层分工

| 层 | 职责 | 禁止 |
|----|------|------|
| **Agent**（宿主模型） | 根据全文上下文、论证关系和阅读目标判断语义功能及优先级 | 不得用关键词规则或脚本代替 |

## Agent 语义分析 schema

Agent 读取全文后，按以下 JSON 格式输出结构化分析结果：

```json
{
  "goal": "聚焦阅读",
  "blocks": [
    {
      "para_idx": 0,
      "text": "根据纽马克的翻译理论……两种侧重形式。",
      "role": "理论定义",
      "priority": "精读",
      "preview": null,
      "emphasis": [
        {"start": 21, "end": 30, "text": "语义翻译和交际翻译", "score": 0.98}
      ]
    },
    {
      "para_idx": 2,
      "text": "例如，在《红楼梦》英译本中……",
      "role": "例证",
      "priority": "跳读",
      "preview": "《红楼梦》英译中缘分的借词实例"
    }
  ]
}
```

### 字段说明
- `para_idx`：自然段索引（0-based）。
- `text`：该语义块的原文，必须在对应自然段中精确定位。
- `role`：语义功能（理论定义/核心论点/论证/例证/背景/过渡/限定/结论/引文）；标题/列表/原文译文对照/表格/分隔线也可作为结构边界角色。
- `priority`：精读 / 速览 / 跳读。
- `preview`：仅跳读块需要，描述"这块是什么"（不复述内容）。
- `emphasis`：可选局部强调数组。`start/end` 为相对本块 `text` 的 `[start,end)` 字符区间；`text` 须与区间原文逐字一致；`score` 用于超限截断。只标核心命题、关键概念与必要逻辑，不按关键词机械加粗。

### emphasis 校验
- 非法区间、越界、原文不匹配、跨块及重叠强调不渲染，并记入 `_meta.diagnostic.emphasis.dropped`。
- 每块最多 3 处，每处最多 15 字；全文加粗非空白字符不超过正文的 5%，按 `score` 截断。
- 无有效强调时保持普通正文；强调失败不影响语义块、阅读策略或原文。
- HTML 仅用文本节点和 `<strong>` 插入强调，不把原文当 HTML 拼接，不改字词、标点或译例。

### Python 三硬约束
1. 每个 block 的 `text` 能在原文中精确定位。
2. block 之间互不重叠。
3. 全部 block 覆盖原文无遗漏（非空白字符一致）。

任一失败 → 该段退回保守处理（整段单块、无标签、不折叠），记录问题段落。

### 保守模式
无 LLM 语义分析时（`analysis=None`）：全文按原文呈现，不贴标签，不折叠。不得把关键词分类冒充语义理解。

## 语义块（非逐句切分）

- 一个语义块可含多句，长度由意义完整性决定。
- 相邻句子属于同一论证功能时合并。
- 默认不跨自然段；段落仍是视觉容器。
- 逐句高亮保留，只在块内部定位句子，不决定切分单位。
- 记录语义块数与块内句子数，供测试判定合并是否生效。

## 三种阅读行为

### 精读
- 完整保留原文。
- 核心论点、必要推理、关键定义适度加粗。
- 需要时提供局部解释，不默认改写。

### 速览
- 默认直接显示主要内容，不需点击展开。
- 是清晰基准态：正常字号、正常字重、正文色，不删减、不改写文字。
- 仅以行长、段距、可选断行做零信息损失排版辅助，不跨语义块。
- 只有聚焦选中其他内容后才暂时减淡；不等于折叠或逐段摘要。

### 跳读
- 仅用于对当前阅读目标非必要的重复例证、次要背景或补充内容。
- 显示一句结构性预览（"这块是什么"），不复述内容。
- 用户可展开完整原文。
- 相邻同主题跳读块合并为一个折叠区；跨主题不合并。

不强制三类占比，不为增加跳读比例而隐藏关键证据。

---

## 60% 诊断（不阻断）

- 统计精读占比、段内切分率、单标签整段占比、问题段落列表。
- 超过 60% 时输出诊断信息，**不阻断输出**，不强行降级。
- 诊断写入 `_meta.diagnostic`。

## HTML 呈现（无标签视觉分层）

取消正文中"重点读/简单读/可略读"标签、段落编号及判断理由。

| 行为 | 视觉 |
|------|------|
| 精读 | 低饱和暖色填充 + 橙红左边框 + 局部 `<strong>`；不整段加粗或染色 |
| 速览 | 无填充、蓝灰细边、正常正文色与字重、较松排版；默认直接可读 |
| 跳读 | 中性灰底 + 始终可见的内容预览 + “展开原文/收起原文” |

- 浅色精读背景 `#FFF2E9`、边框 `#CC6437`；短词强调用 `#A8431F`，避免低对比橙红文字。
- 深色使用独立暖色区域与更亮边框；护眼使用低刺激暖色，不直接照搬浅色值。
- 所有正文相同基础字号，允许统一调整；不仅靠颜色区分，不大面积使用彩色字体。
- 连续同策略块合并为一个视觉区域；跨自然段也可连续，但标题、列表、引文、对照、表格等结构边界断区。
- 背景保持统一强度，不设长度上限、不做衰减；每个区域起点保留 10px 间隙，左边框两端自然收口，无外框、阴影或卡片化。
- 合并与起点标记只改变视觉布局，不改变原文顺序、语义块数据或阅读策略；整页同色应查看诊断并调整 Agent 路由，不用样式掩盖。
- 跳读预览置于 `<summary>`，折叠时仍可见；相邻同主题合并，跨主题不合并。

### 全局原文
- 取消逐段“查看原文”，仅保留工具栏全局“查看原文/返回辅助”和跳读局部展开。
- 原文模式按输入逐字、逐分段显示全文，包括已折叠内容；撤销辅助排版，不生成第二份辅助文本。
- 原文模式同时清除局部加粗、强调色、背景填充、左边框、起点标记、阴影和焦点样式，仅呈现原始文本与原始分段。
- 切换保留字号、行距、主题并定位当前阅读块；保留“全部展开/恢复折叠”，按钮状态与实际折叠一致。

## 聚焦高亮与减淡

- 高亮默认关闭，开启后点句进入聚焦；点击空白或按钮不改变焦点。
- 当前句使用柔和背景，跨行以 `box-decoration-break: clone` 保持连续；当前语义块正常，其他块减淡。
- 聚焦期间精读暖底与跳读灰底让位为中性，仅保留边框，避免与高亮叠加。
- 深色高亮使用 `#5A4718` 等暖褐底，高亮文字与底色对比度 ≥4.5:1，且与页面背景有可测亮度差。
- **减淡用文字颜色变量（--fg-dim），不用整体 opacity。** 正常正文约 7:1 时，减淡到 4.5–5:1 即足够。
- 关闭高亮立即恢复填充与文字；折叠/展开/模式切换/原文切换后恢复或清理失效焦点。
- 上一句/下一句跳过折叠和隐藏内容。

## 高风险文本
- 药品说明书/合同/法律：默认完整阅读，不折叠，不标跳读。
- 不自动省略警示/限定/关键条件/例外。
