# HTML 阅读器呈现与交互规范（V4.0）

仅在实际生成或修改 HTML 阅读器时读取。语义判断、比例复核和标题识别以 `routing.md` 为唯一权威来源，本文件不重新判断重要性。

## 呈现

- 精读：低饱和暖色填充、橙红左边框、必要的局部 `<strong>`；不整段加粗。
- 速览：无填充、正常正文色与字重，完整显示原文，不删减、不改写。
- 跳读：无填充、低对比虚线边、灰色结构性预览，可逆折叠；预览只说明“这块是什么”。
- 普通正文统一 `--body-max-width`，精读、速览及展开的跳读正文左边缘对齐。
- 连续同策略块合并视觉区域；标题、列表、引文、对照、表格等结构边界断区。合并不改变块数据。
- 文档主标题 `<h1>`，一级章节 `<h2>`，二级章节 `<h3>`，更深层级按实际递增；标题不使用阅读策略底色。
- 三主题均用 CSS 自定义变量；正常文字、聚焦文字及减淡文字对比度不低于 4.5:1。

## 视图与控件

- 默认统一“辅助阅读”视图：精读、速览直接可见，跳读默认折叠并显示预览。
- 保留全局“查看原文/返回辅助”、“全部展开/恢复折叠”和独立逐句高亮开关，三者可独立组合。
- 原文视图逐字恢复输入及原始分段，清除辅助加粗、填充、边框和区域标记；切换保留阅读位置和用户设置。
- 不再提供三模式按钮，不恢复底部固定导航、底部进度条或悬浮上下句工具条。

## 聚焦与取消

- 高亮默认关闭。开启后点击句子聚焦；点击其他句切换焦点。当前句使用柔和背景，其他正文用文字颜色变量减淡，不使用整体 opacity。
- 点击 `.sent` 及其中的 `<strong>` 正常聚焦；标题、`<summary>`、按钮、下拉框和 `[data-control]` 不清除焦点。
- 用 `caretRangeFromPoint` / `caretPositionFromPoint` 与字符矩形共同判断真实文字命中；点击块内留白、区域间距或阅读区边缘时调用 `clearFocus()`。
- 有文字选区时不清除焦点；Esc 只清除当前聚焦，不改变设置。
- 辅助视图和原文视图共享焦点状态；关闭高亮后恢复所有文字与填充。
- 可选桌面键盘导航直接调用 `moveFocus(1)` / `moveFocus(-1)`，不依赖按钮，也不影响触屏。

## 滚动与底部留白

- 页面只保留顶部 sticky 工具栏。**不存在 `footer`、`#prev`、`#next`、`#pos` 或 `footerEl`。**
- `main` 使用正常底部留白：`--bottom-gap:calc(32px + env(safe-area-inset-bottom,0px))`，不再为固定底栏动态增加大留白。
- `ResizeObserver` 只观察 header，用于更新 `--header-height`；窗口 resize 与 orientationchange 同步更新。
- 聚焦安全区上界为 `headerEl.getBoundingClientRect().bottom + 8`，下界为 `window.innerHeight - 8`；只处理顶部遮挡和真实可视区域。
- 最后一句必须能完整滚动显示并聚焦；24px 字号、宽松行距、跳读展开及窄屏下均适用。
- 不禁止 `body` 滚动，不用固定高度掩盖溢出。若宿主 iframe 禁止滚动或跨域限制访问，应报告宿主限制，并提供独立浏览器打开方案。
