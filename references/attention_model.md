# 注意力模型 · ACS 公式与阈值（V2.0）

> ACS（Attention Cost Score）∈ [0, 100]，由 `scripts/acs.py` 计算，模型不得估算。

## 0. 定位（V2.0 重要修订）

- ACS 衡量 **文本结构复杂度**（客观可计算），**不是** 已验证的用户认知负荷测量值。
- 三者分开：
  - **文本结构复杂度** = ACS（客观）。
  - **用户主观阅读负荷** = 因人而异，不由 ACS 单独判定。
  - **阅读优先级** = 内容结构 + 用户目标，见 `routing.md`。
- ACS 可作为"是否需要更细分段/更强辅助"的参考信号，不得作为唯一判据，更不得宣称为医学标准。

---

## 1. 总公式

```
ACS = 40·S_sentence + 25·S_vocab + 15·S_pronoun + 10·S_nest + 10·S_line
```
权重和 = 100，各项 ∈ [0,1]，故 ACS ∈ [0,100]。

## 2. 各项定义

### 2.1 平均句长 `S_sentence`（权重 40）
- 句长 = 段总字数 / 句子数（按。！？；切）。
- `S_sentence = clamp((avg_len - 15) / 25, 0, 1)`：≤15字→0，≥40字→1。

### 2.2 生词密度 `S_vocab`（权重 25）
- 生词 = 不在常用字表内的字（按字计）。常用字表 = GB2312 一级字库 3755 字（近似 3500 常用字表）。
- `S_vocab = clamp(oov_ratio / 0.10, 0, 1)`：占比 0%→0，≥10%→1。

### 2.3 指代距离 `S_pronoun`（权重 15）
- 代词（它/其/该/此/这/那/上述/本人/自己/他/她…）到最近先行实词的字距。
- `S_pronoun = clamp(max_dist / 60, 0, 1)`；无代词则 0。

### 2.4 嵌套深度 `S_nest`（权重 10）
- 括号层级 + 从句标记（因为/所以/虽然/但是/如果…）最大嵌套层数。
- `S_nest = clamp((max_depth - 1) / 3, 0, 1)`：≤1→0，≥4→1。

### 2.5 行长超限率 `S_line`（权重 10）
- 行长上限 40 字（仅作结构指标；实际行长由展示层动态控制）。
- `S_line = clamp(overlimit_ratio / 0.20, 0, 1)`。

---

## 3. 阈值与动作

| 对象 | 条件 | 动作 |
|------|------|------|
| 单段 | ACS > 60 | 建议切分（软性，按语义边界切，不机械断句） |
| 全文 | 均值 > 45 | 输出"建议分篇/分段阅读" |
| 全文 | 均值偏高 | 建议更强辅助模式（征求用户，不强制） |

> V2.0：切分/分篇为**软性建议**，不再"强制"。是否切分还须结合语义完整性与用户目标。

## 4. 用户层难度描述（不展示原始 ACS）

| ACS | 阅读难度描述 |
|-----|--------------|
| 0–25 | 较低 |
| 26–50 | 适中 |
| 51–75 | 较高 |
| 76–100 | 很高 |

## 5. 预检测说明（方案B）

- CodeArts 无"Skill 加载前执行脚本"的钩子，**不在 Skill 激活前跑 ACS**。
- 流程：Skill 经 description 匹配被选中 → 运行 ACS → 若均值偏高，提示"部分段落结构较复杂，是否使用更强辅助模式？" → 用户同意则增强，拒绝则正常处理，不反复询问。
- 预检测分数（若未来宿主支持）须与完整 ACS 区分，不得混用。
- 阈值可配置，**不宣称为经实证验证的医学标准**。
