# 注意力模型 · ACS 公式与阈值（V2.1）

> ACS（Attention Cost Score）∈ [0, 100]，由 `scripts/acs.py` 计算，模型不得估算。

## 0. 定位与可见性（V2.1）

- ACS 衡量 **文本结构复杂度**（客观可计算），**不是** 用户认知负荷测量值。
- **三者不可互换**：文本结构复杂度 / 用户主观阅读负担 / 内容重要性。
- **用户端默认隐藏** ACS：不显示数值、公式、复杂度图、权重、日志及任何开发者指标。
- 必要时只给**自然语言提示**（如"这段句子较长，建议分段读"），提示由结构规则生成，不暴露分数。
- **开发者端保留真实计算**，仍由 `scripts/acs.py` 出分，不得模型臆测。
- ACS 只用于**推荐辅助方式**，不决定阅读优先级。

---

## 1. 总公式

```
ACS = 40·S_sentence + 25·S_vocab + 15·S_pronoun + 10·S_nest + 10·S_line
```
权重和 = 100，各项 ∈ [0,1]，故 ACS ∈ [0,100]。

## 2. 各项定义

### 2.1 平均句长 `S_sentence`（权重 40）
- 句切分：全角 `。！？；` 与半角 `.!?;`（适配中英混排）。
- `S_sentence = clamp((avg_len - 15) / 25, 0, 1)`：≤15字→0，≥40字→1。

### 2.2 生词密度 `S_vocab`（权重 25）
- 生词 = 不在常用字表内的中文字。常用字表 = GB2312 一级字库 3755 字。
- 无中文字的纯英文段 → `S_vocab = 0`（英文词汇难度不由中文字表衡量，标注为限制）。
- `S_vocab = clamp(oov_ratio / 0.10, 0, 1)`。

### 2.3 指代距离 `S_pronoun`（权重 15）
- 中文代词到最近先行实词字距。`S_pronoun = clamp(max_dist / 60, 0, 1)`；无代词则 0。

### 2.4 嵌套深度 `S_nest`（权重 10）
- 括号层级 + 从句标记最大嵌套层数。`S_nest = clamp((max_depth - 1) / 3, 0, 1)`。

### 2.5 行长超限率 `S_line`（权重 10）
- 行长上限 40 字（结构指标；实际行长由展示层动态控制）。
- `S_line = clamp(overlimit_ratio / 0.20, 0, 1)`。

---

## 3. 阈值与动作（软性）

| 对象 | 条件 | 动作 |
|------|------|------|
| 单段 | ACS > 60 | 建议切分（按语义边界，不机械断句） |
| 全文 | 均值 > 45 | 输出"建议分篇/分段阅读" |
| 全文 | 均值偏高 | 建议更强辅助模式（征求用户，不强制） |

切分/分篇为**软性建议**，须结合语义完整性与用户目标。

---

## 4. 用户层难度描述（不展示原始 ACS）

| ACS | 描述 |
|-----|------|
| 0–25 | 较低 |
| 26–50 | 适中 |
| 51–75 | 较高 |
| 76–100 | 很高 |

---

## 5. 已知限制（须人工复核）
- 纯英文词汇难度不由本表衡量（`S_vocab=0`）。
- 极短段落 ACS 偏低是正确行为（短=结构简单），但可能仍含关键信息——优先级由 routing.md 语义判定，不由 ACS 决定。
- 文学引文/译文的结构复杂度按字面计算，文化负载不纳入。

---

## 6. 预检测说明（方案B）
CodeArts 无"Skill 加载前执行脚本"钩子，不在 Skill 激活前跑 ACS。流程：description 匹配 → Skill 内跑 ACS → 偏高则建议更强辅助（征求用户，不反复询问）。不声称自动监听。阈值可配置，不宣称为医学标准。
