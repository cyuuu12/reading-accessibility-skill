# 变换规则 · 语义块 + 动态软约束 + L0/L1（V2.3）

> V2.3：语义分析由 Agent 完成；语义块替代逐句切分；精读/速览/跳读是阅读行为；
> HTML 去标签视觉分层；Markdown 保留原文主体；统一处理层 analyze.py。

---

## 0. 三层阅读机制（与 routing.md 对应）

- **第一层 整篇模式**：完整阅读 / 聚焦阅读 / 快速浏览。
- **第二层 段内语义单元策略**：同一段可有不同策略的单元（精读/速览/跳读），不强制一段一种策略。
- **第三层 注意力辅助**：逐句高亮、字号、行距、背景、折叠、原文切换、进度——独立运行，不决定段落可见性。

---

## 1. 模块化理解框架（替代单一浓缩结论）

复杂结构无法用一句结论支撑。改为按**语义结构**组织若干互相关联的模块。

模块示例：理论依据 / 核心问题 / 解决方法 / 方法局限。

约束：
- 模块数量不固定；字数不强制统一。
- 标题须概括**真实语义功能**，不得机械套"背景—问题—方法—结论"。
- 叙事/说明/议论/学术各用其结构。
- 保留限定、条件与逻辑关系；关系明确时可用简洁箭头（→）。
- 模块是**理解框架**，不替代正文。
- 移动端自动纵向布局。

---

## 2. 动态长度原则（软性）

- **结论/模块**：长度由核心信息量决定，优先简洁，不删必要条件/数字/限定。
- **要点**：数量由论证结构定，每条一个完整信息单元。
- **单行**：按语义边界/标点/显示环境调整，不机械切断。
- **段落**：按内容组织动态变化。
- **不可改变**：数字/单位/否定/限定/因果/条件/比较/范围。
- 拆分程度由内容结构决定；字体/行距等视觉参数交展示层控制。

## L1 叠加层（按需开启）

### 1. 语音型（phonological）
触发：儿童科普、注音、朗读。动作：按音节切分；多音字标拼音（保真不换字）；同音易混词加注。

### 2. 快速命名型（rapid naming）
触发：ADHD、流畅度低、术语堆叠。动作：高频词打包词块；名词串插连接词；术语首现给 ≤3 字短释。

### 3. 正字法型（orthographic）
触发：形近字易混、部件识字。动作：形近对比；部件拆解；禁半词加粗。

### 4. 语义型（semantic）
触发：一词多义、抽象术语密集。动作：语义锚；一词一义；必要时常用同义词替换（保真前提下）。

### 5. 低视力（low vision）
触发：视力低/老年/高对比。动作：对比度≥4.5:1、字号≥18px、行距≥1.5 倍建议；不改文字，交 HTML 阅读器实现。

| 模式 | L0 | L1 | 折叠 |

## Markdown 输出原则（V2.2 大幅简化）

Markdown 是轻量降级方案，不再追求模拟完整阅读器。

- 默认取消独立阅读路线和逐段策略说明。
- 保留原文顺序与主体内容。
- 仅在需要处用少量加粗、段落分隔和简短解释。
- 不为每段生成标题，不反复出现"重点读/简单读"标签。
- 不默认逐段总结或改写全文。
- 模块化理解框架仅在复杂文本确有必要时简洁展示，不机械生成。
- 三级策略只在 HTML 或宿主原生组件中表达；Markdown 不承载三级标签。
- 折叠、即时切换、字号控制等交由 HTML 或宿主原生组件处理。

**Markdown 的任务是辅助阅读原文，而非生成另一篇文章。**
